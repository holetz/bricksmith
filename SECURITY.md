# Security policy

## Supported versions

bricksmith has not been released yet. Once it is, security fixes land on the latest release only.

## Reporting a vulnerability

Please report vulnerabilities privately, never in a public issue or pull request:

- **Preferred:** GitHub private vulnerability reporting, from the repository's
  [Security tab](https://github.com/holetz/bricksmith/security/advisories/new).
- **Email:** holetz@gmail.com, with `bricksmith security` in the subject.

Include the affected version or commit, a description of the impact and the steps to reproduce.
Do not include real credentials, workspace URLs or data in the report.

## What to expect

- An acknowledgement within 7 days.
- An assessment and, when the report is confirmed, a planned fix and disclosure date agreed with you.
- Credit in the advisory and the changelog, unless you prefer to stay anonymous.

Confirmed vulnerabilities are published as GitHub security advisories and recorded in
[CHANGELOG.md](CHANGELOG.md) with the release that fixes them.
