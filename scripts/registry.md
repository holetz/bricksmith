# Operations registry

Repository operations live in `scripts/` and are reached through the [`justfile`](../justfile) at the
repository root (`just <recipe>`). The library's own command line is `[project.scripts]` in
`pyproject.toml`, not this surface.

## Lifecycle

| Entry point | Router recipe | Lifecycle |
| --- | --- | --- |
| `setup.sh` | `setup` | active |
| `leak_check.py` | `check`, `leak-check` | active |
| `build_kernel.py` | `build-kernel` | active |
| `verify_dist.py` | `verify-dist` | active |
| `features_benchmark.py` | `features-benchmark` | active |
| `bootstrap.py` | — (shared module imported by the other scripts) | active |
