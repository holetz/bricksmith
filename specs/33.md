## Problem

On a Windows checkout of main @105c814, the local gate (`uv sync --locked`, `uv run ruff check`, `uv run pyright`, `uv run pytest`) is not green, and the spec store can resolve to the wrong backend. Three independent causes were observed: `.claude/quenching.json` is committed as a symlink (mode 120000) that Windows without symlink privilege checks out as a text file; `uv run pyright` reports 29 reportMissingImports for optional heavy integrations that the default groups deliberately omit; two tests assume POSIX (a `venv/bin/python` path and permission to create symlinks).

## Proposal

Fix each cause in its own small PR so that a fresh Windows checkout runs the unchanged gate command to green without optional extras, while Linux/CI behavior stays identical. Order: ship the regular config file first (the spec store must resolve to `backend: git` before any other spec is tracked from Windows), then the type-check and test-portability fixes in parallel.

## Out of Scope

Changing CI workflows, hook scripts or the gate command; adding heavy integrations to default dependency groups; the Windows hook interpreter and CI billing issues (tracked as human decisions in epic 6).

## Validation

On a Windows checkout without symlink privilege: `cq specs config` reports `backend: git`; `uv sync --locked && uv run ruff check && uv run pyright && uv run pytest` exits 0 with no optional extras installed. On Linux the same gate stays green and skipped tests are only the documented platform-specific ones.

## Design

Intended members and order. Each member is one PR with its own verifiable end state.

- Wave 1. Spec store config: #34 Ship .claude/quenching.json as a regular file (low). No dependencies.
- Wave 2. Windows gate [P]: #35 Type-check gate green without optional extras (medium), after #34; #36 Gate tests portable to Windows (low), after #34. #35 and #36 touch disjoint files (pyproject.toml plus optional-integration modules and tests/unit/dab, versus scripts/verify_dist.py and tests/unit/io/test_volumes.py), so they can run in parallel.

Related human decisions are tracked in epic #6: #37 (hook interpreter on Windows) and #38 (CI refused by GitHub billing).
