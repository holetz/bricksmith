## Problem

Specs 153 and 154 (epic 139) were verified with structural tests and fake SQL/Jobs clients only: no run had workspace credentials. The generated AI/BI dashboard has not been deployed and queried, the console's Statement Execution and Jobs calls have not run against a warehouse, and the Databricks App bundle resource named in spec 154's proposal was not delivered.

## Proposal

- Extend the remote Free Edition proof: deploy the example with the stability dashboard, query every dashboard dataset, and drive a mark and a reprocess through the console verbs with one explicit free profile.
- Add the Databricks App bundle resource for the console (on-behalf-of-user authorization) and deploy it in the same proof.
