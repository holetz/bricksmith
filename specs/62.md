## Problem

Reproduced 2026-10-23 by the autopilot conductor on main (af18d01), from the round Codex review (range e2742f7..af18d01):

`redact_text('passwords=["alpha", "beta"]')` → `passwords=<redacted>"alpha", "beta"]`; the same shape leaked on e2742f7 with `secret=["alpha", "beta"]` → `secret=<redacted>"alpha", "beta"]`. Cause: `src/bricksmith/ops/redact.py:139`, the unquoted-value matcher consumes only the `[`, leaving every list element in clear.

Consequence: a secret key whose value is a list (YAML flow sequence, JSON array, Python repr) prints each secret. Mask the whole bracketed value up to its matching `]` on the same line, keep #41's linear-time bound.
