## Problem

Gap left by #62 (PR #114), reproduced by the round-1 reviewer on 2026-11-26 (main 48f4a94):

```
.venv/bin/python -I -c 'import sys; sys.path.insert(0,"src"); from bricksmith.ops.redact import redact_text as r; print(repr(r("\"passwords\": [\n  \"hunter2\",\n  \"swordfish\"\n]")))'
'"passwords": <redacted>\n  "hunter2",\n  "swordfish"\n]'
```

`_bracketed_end` at `src/bricksmith/ops/redact.py:168-169` stops at the first newline even when the `[` is unclosed, so pretty-printed JSON/YAML lists under a secret key expose every element. Consequence: secrets in formatted config dumps leak. Must stay linear-time (#41) on unclosed or deeply nested brackets.

## Proposal

- Make `_bracketed_end` in `src/bricksmith/ops/redact.py` continue across newlines while a `[` is open, so every element of a pretty-printed list under a secret key is masked.
- An unclosed `[` keeps the previous behavior (mask to the end of the first line).
- Add the reviewer's reproduction as a regression test; keep the #41 linear-time bound.

## Out of Scope

- Brace-delimited multi-line objects under a secret key.

## Impact

### Product code this spec expects to touch

- `src/bricksmith/ops/redact.py` — `_bracketed_end` and its caller
- `tests/unit/ops/test_ops.py` — regression and linear-time cases

## Validation

- `uv run pytest tests/unit/ops -q` passes, including the linear-time tests.
- `uv run ruff check && uv run ruff format --check && uv run pyright` are clean.

## Design

- A newline inside an open bracket no longer ends the value; when the scan reaches the end of the text without closing, the value falls back to the end of its first line.
- Linear time: failed (unclosed) scans draw from a shared budget proportional to the text length; once spent, later brackets fall back to single-line masking, so adversarial `secret=[` repetitions cost O(n).
- Epic 168 decision (2026-11-26): forced develop, approved by orchestrator-forced.

## Alternatives Considered

- Stop at the first blank line: rejected, pretty-printed lists may hold blank lines and the rule leaks.
- Unbudgeted rescans of unclosed brackets: rejected, quadratic on repeated `secret=[`.

## Open Decisions

- none — the epic's design fixes the direction.

## Risks

- A stray unclosed `[` followed by a later `]` masks the text between them; over-masking errs toward not leaking.
