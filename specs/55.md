## Problem

Reproduced 2026-10-17 by the epic #47 correctness review on main (6f3ef40), range 77e04d9..6f3ef40.

`redact_text('password: | # note\n  s3cretvalue\nuser: bob')` → `password: <redacted> # note\n  s3cretvalue\nuser: bob`. Cause: `src/bricksmith/ops/redact.py:33`: `_BLOCK` allows only blanks between the `|`/`>` indicator (with optional chomping and indentation digit) and the newline, so a trailing `# comment` falls through to the bare-value path, which masks only `|`.

Consequence: valid YAML with a comment after a block-scalar indicator prints the secret lines in clear. Keep #41's linear-time bound.
