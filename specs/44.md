## Problem

The catalog guide says "nothing is time dependent", but `src/bricksmith/catalogdocs/cli.py:22`
calls `load_graph(args.project)` without `today`, so graph validation falls back to the current
UTC date (`src/bricksmith/graph/build.py:260`).

Reproduction (synthetic project with one `[[exemptions]]` entry expiring 2026-12-31, 2026-10-16):
with `today=2026-10-16` the catalog carries `('warning','unused_exemption','x:y',…)`; with
`today=2027-01-01` it carries `('error','expired_exemption','x:y','exemption expired on 2026-12-31…')`.

Consequence: the same project renders different bytes on different days, breaking the
deterministic offline catalog contract of spec 3 (diffs and reviews churn without changes).
