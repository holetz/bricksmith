# Redact entire quoted secret assignments with whitespace

## Problem

Independently reproduced on 2026-10-14: ops/redact.py:24 excludes whitespace from assignment values. redact_text('password="synthetic alpha beta"') returns 'password="<redacted> alpha beta"', leaking the secret suffix into events/reports. Same quoted-token structure is vulnerable. High-severity correctness/security finding; all inputs are synthetic.

Reproduce with `.venv/bin/python` using this stdin (synthetic only):

```python
from bricksmith.ops.redact import redact_text
print(redact_text('password="synthetic alpha beta"'))
# Observed: password="<redacted> alpha beta"
```

## Proposal

Mask complete quoted assignment values before general unquoted handling, preserving useful surrounding nonsensitive text and bounding output.

## Out of Scope

New logging surfaces, executable grants, dependency changes and using real credentials in fixtures.

## Impact

src/bricksmith/ops/redact.py; tests/unit/ops/; docs/guide/operations.md if the public contract needs clarification.

## Validation

Synthetic passwords/tokens with spaces, both quote kinds, quoted delimiters, malformed/truncated quotes, multiline/escaped input, nested redact_value text, existing bearer/URL/row masking and length bounds. Independent verifier repeats the exact repro, checks suffix absence and runs gate.

## Design

Stop override: the dated delegation below is historical and cannot resume this paused run.

Full sensitive value is redacted; ordinary text after a closed quoted assignment is retained. Handle escaped delimiters deliberately, with tests defining conservative malformed-input behavior. Preserve API, stdlib-only implementation, exact-secret replacement and output limit.

Autonomy delegated by the human invocation on 2026-10-14: ordinary product implementation, verification, commit, push and PR are authorized after verifier PASS; merge additionally requires green CI. Executable grants/surfaces, generated CI/hooks/scripts and plugin runtime expansion are never forced and belong to the human-decision epic. No publishing or visibility changes.
