## Problem

Regression introduced on PR #21 (spec #42, branch plan/42-mask-secret-values, f01b32b); main (cbe316f) is correct. Blocks merging PR #21 as-is.

Reproduced 2026-10-17 by the epic #47 correctness review: on the PR, `clientsecret=s3cretval`, `accesstoken=…`, `authtoken=…`, `sessiontoken=…`, `refreshtoken=…`, `apitoken=…`, `secretkey=…`, `dbpass=…` and quoted `clientsecret: 's3 cret'` come back unmasked; main masks all of them. Uppercase forms (`ACCESSTOKEN=`) are still masked.

Cause: `src/bricksmith/ops/redact.py:22-24` (PR branch): the keyword boundary lookarounds are case-sensitive, so `(?![a-z])` rejects lowercase continuations; only `password|passwd|passphrase|apikey` may sit inside a longer word.

Consequence: common env/config spellings that main masked now leak secret values into logs. Fix on the PR branch before merge (or as the first follow-up), with regression tests for every key above in lower, upper and mixed case; keep #41's linear-time bound.

## Proposal

Allow secret, token, secretkey and db/user/sql/ftp/ssh/admin/root-prefixed pass to sit inside a longer lowercase word in the keyword pattern.

## Out of Scope

- none — only the keyword boundary changes.

## Impact

- src/bricksmith/ops/redact.py and tests/unit/ops/test_ops.py.

## Validation

- Parametrized test: eight keys in lower, upper and title case, bare and quoted; existing guards (bypass, compass, tokens) stay green; linear-time test stays green.

## Design

Extend _KEYWORD with explicit compound alternatives; the trailing no-letter lookahead keeps tokens and bypass unmasked.

## Alternatives Considered

- Dropping the lowercase boundary entirely: rejected, it over-redacts bypass and compass.

## Open Decisions

- none — the db/user/sql/ftp/ssh/admin/root pass prefixes are a closed list.

## Risks

- A new prefix spelling leaks until added; the list is explicit and extendable.

## Tasks

- [x] 1.1 Allow lowercase compound secret keys and add regression tests
  - files: src/bricksmith/ops/redact.py, tests/unit/ops/test_ops.py

## Outcome

Shipped: the redaction keyword pattern now also masks lowercase compound secret keys (clientsecret, accesstoken, authtoken, sessiontoken, refreshtoken, apitoken, secretkey, dbpass) in any case, with a parametrized regression test. Nothing left out. Reviewed: single task, two files; gate green (pytest 506 passed). No emergent docs or release obligations.
