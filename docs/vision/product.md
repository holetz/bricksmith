# Product record

## Platform

web

## Users

Data and machine-learning engineers who build, ship and monitor Databricks data projects, and the coding agents that work beside them. They read the documentation site and the generated reports and run the library from notebooks, jobs and the command line.

## Product Purpose

Make a Databricks data project a plain folder tree: catalogs, schemas and tasks are discovered from where they live, task dependencies are inferred from the code that reads them, bundle resources are built natively in Python, and data, MLOps and monitoring tasks share one discovery, dependency graph and runner.

## Positioning

One open-source Python library with an updatable project template and an optional Claude Code plugin, instead of a set of separate products or generated YAML. Its visual surfaces are documentation and reports: legible, technical and quiet, so the data and the decisions stay in front.
