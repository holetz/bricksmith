## Decision

Everything in this repository is written in English: code, identifiers, docstrings,
documentation, agent skills, commit messages, pull requests and specs.

Project data may use a configured naming vocabulary in another language. The library's default
preset is neutral and independently designed; it does not carry the private reference's prefixes
or naming grammar. Projects supply their own vocabulary without changing the library.
