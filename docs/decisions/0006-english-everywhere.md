# 0006. English everywhere

- Status: accepted
- Date: 2026-10-11

## Decision

Everything in this repository is written in English: code, identifiers, docstrings,
documentation, agent skills, commit messages, pull requests and specs.

The one opinionated exception is data, not prose: the default naming preset of
`bricksmith-registry` uses the column prefixes of the reference implementation (`dt_`, `vl_`,
`cd_` and the rest), which are abbreviations rather than English words. A project can replace the
preset.
